## 📌 About

**Group Finder** is a simple and modern web application that lets students quickly find their assigned group based on their last name.

Instead of manually checking the group list, simply enter your name and the application will automatically determine your group.

## 🚀 How It Works

The application normalizes the entered last name and compares it with the group boundaries.

For example:

```text
AMEN  → G2
BOUH  → G3
FARR  → G5
OUBA  → G7
```

The result is displayed instantly without needing to reload the page.
